- **Decision:** First-release registration is **self-service and
  auto-approved, gated by owner-provisioned device-account credentials**. No
  approval workflow is selected (TASK-1507's conditional scope is therefore
  not triggered). `Discovered` and `PendingApproval` are reserved, unreachable
  states. Owners may optionally pre-create machine records that a registering
  agent binds to.
