# TASK-1506: If an alternate path is approved, normalize it through the same power-reading command and idempotency rules as agent polling

## Objective

If an alternate path is approved, normalize it through the same power-reading command and idempotency rules as agent polling.

This task contributes to [EPIC-15: Reporting And Future Ingestion](../epics/EPIC-15.md)
and must preserve the epic outcome: Add bounded aggregate reporting and prepare alternate power paths without changing the established machine, meter, or reading ownership model.

- The same vendor event through two paths produces one logical reading.
- All prerequisite behavior remains passing after this change.
- No credentials, API keys, refresh tokens, or sensitive configuration values
  are committed, persisted in plaintext, or emitted to logs.
- Failures are explicit and actionable; the implementation does not silently
  discard telemetry, authorization failures, migration errors, or installer
  errors.
