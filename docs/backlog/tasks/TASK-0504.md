# TASK-0504: Normalize OS, architecture, machine name, agent version, CPU, memory, and storage values without silently coercing invalid data

## Objective

Normalize OS, architecture, machine name, agent version, CPU, memory, and storage values without silently coercing invalid data.

This task contributes to [EPIC-05: Machine Registration And Heartbeat Ingestion](../epics/EPIC-05.md)
and must preserve the epic outcome: Register machines independently and ingest validated, idempotent heartbeats through an authenticated end-to-end path.
