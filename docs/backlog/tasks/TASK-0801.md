# TASK-0801: Define a durable queue interface and record envelope containing original event time, sequence/idempotency key, payload version, attempt count, and next attempt time

## Objective

Define a durable queue interface and record envelope containing original event time, sequence/idempotency key, payload version, attempt count, and next attempt time.

This task contributes to [EPIC-08: Offline Queue And Resilient Delivery](../epics/EPIC-08.md)
and must preserve the epic outcome: Preserve telemetry through transient API outages without unbounded disk use, duplicate records, or blocked service shutdown.
